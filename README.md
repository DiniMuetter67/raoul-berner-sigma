# RAOUL BERNER — Sigma One-Pager

Dark Mode only. Mobile-first. Minimal JS. Glitch + Reveal + Mini-Toast.

## Lokal starten
Option A (easy):
- Dateien in einen Ordner packen (`index.html`, `styles.css`, `script.js`)
- `index.html` im Browser öffnen

Option B (lokaler Server, recommended):
- Node:
  - `npx serve .`
  - dann die URL öffnen

## Deploy
### Netlify
- Ordner hochziehen (Drag & Drop) oder Git Repo verbinden

### Vercel
- Repo importieren
- Framework: „Other“
- Output: statische Dateien

### GitHub Pages
- Repo erstellen
- Dateien pushen
- Pages aktivieren (Branch: main, root)
